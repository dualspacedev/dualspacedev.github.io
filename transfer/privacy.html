Privacy Policy

File Transfer · Effective July 13, 2026

Summary. File Transfer is designed for direct file transfer. We do not operate a remote server that receives your files, installed-app list, camera images, or transfer history. The app temporarily operates a local server on the sending device when you start a transfer. Transfer content stays on your devices and the devices you choose. Local network transfers use unencrypted HTTP, so you should use the app only on networks and with recipients you trust.

1. Scope

This Privacy Policy explains how File Transfer accesses, uses, stores, and discloses information when you use its Android application. File Transfer does not require an account and does not include advertising or analytics services in the current version.

2. Data the app accesses

Files and media you choose

The app accesses only files, photos, videos, or other content that you select through Android's system pickers, receive through Android sharing, or choose for transfer. File contents and metadata such as file name, type, and size are used to display and transfer your selection.

Installed applications

If you open the Apps picker, the app queries launchable applications installed on your device and reads their app name, icon, package name, version, package size, and APK locations. This inventory is processed locally. The app exports an APK or APKS archive only for applications you explicitly select.

Camera

Camera access is used only while you scan a transfer QR code. Camera frames are analyzed on-device and are not saved or transmitted by File Transfer.

Nearby devices and local network information

Nearby transfer uses Android network service discovery and local network connections. The app processes a device display name, a locally generated device identifier, local IP address, service address, transfer token, pairing code, and transfer status so devices can discover and connect to each other. The identifier is stored on your device and announced only on the active local network while Nearby receiving is enabled. File Transfer does not request location permission or use this information to determine your physical location.

Download and app settings

The app reads Android Download Manager records created by File Transfer to show transfer progress and received files. It stores your theme preference locally. The app does not create a user profile or account.

3. How data is used

Information is used only to provide features you request, including selecting content, discovering nearby devices, creating a local transfer link or QR code, sending and receiving files, showing progress, exporting selected application packages, opening files, and remembering display preferences.

We do not sell your data, use it for advertising, build behavioral profiles, or send it to a developer-operated analytics or cloud storage service.

4. Sharing and transfers

When you initiate or accept a transfer, the selected content and necessary transfer metadata are disclosed to the recipient device you choose. When you use Android's system share sheet, information is handled by the receiving application under that application's own terms and privacy policy.

Android and Google Play may independently process app distribution, security, and diagnostic information under their own policies. File Transfer does not control those platform services.

5. Storage and retention

  • Selected files: selection and transfer state are kept in memory for the active app session. For files chosen through Android's document picker, Android may grant File Transfer persistent read access so the selected content remains available during a transfer. You can revoke that access by clearing app data, uninstalling the app, or changing access through Android or the document provider where supported.
  • Received files: downloads are saved in the public Downloads/File Transfer folder and remain until you delete them.
  • Exported APKS files: split application archives are stored in the app cache and may remain until Android clears the cache, you clear app storage, or you uninstall the app.
  • Single APK selections: the app reads the existing installed APK directly and does not create a duplicate cache copy.
  • Theme preference: remains on the device until changed, app data is cleared, or the app is uninstalled.
  • Nearby device identifier: remains in app preferences until app data is cleared or the app is uninstalled.

Because File Transfer does not maintain user accounts or a developer cloud database, there is no remote account data to delete. You can remove local data through the app, Android settings, the system file manager, or by uninstalling File Transfer.

6. Security

File Transfer limits content access through Android content URIs, read grants, short-lived session tokens, pairing codes, and app-private components. Nearby requests require recipient confirmation where supported.

Important: local link, QR, and nearby file delivery currently use HTTP on the local network and are not end-to-end encrypted by File Transfer. Anyone who obtains an active transfer link and pairing code and can reach the sender's local network service may be able to request the shared content. Use trusted networks, verify the recipient, do not post transfer links publicly, and stop the sharing session when finished.

7. Your choices and permissions

You may decline camera permission; QR scanning will not work, but you can continue using other available transfer methods. File Transfer does not request location, nearby-device, or notification permission. Android system settings let you revoke camera permission, clear cache or app data, and remove downloaded files.

8. Children

File Transfer is a general-purpose utility and is not directed to children under 13 or the minimum age required by local law. We do not knowingly collect personal information from children through a developer-operated service.

9. Changes to this policy

We may update this policy when features, legal requirements, or data practices change. The effective date at the top identifies the latest version. Material changes will be made available through the app or its store listing as appropriate.
